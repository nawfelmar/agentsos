# Relay call sounds

Calm enterprise cues — soft bells over a quiet pad. Not a phone ringtone.

Regenerate:

```bash
python3 scripts/generate-call-sounds.py
```

| File | Role |
|------|------|
| `relay-ring.wav` | Soft looping bed while connecting |
| `relay-connected.wav` | Quiet acknowledgment when answered |
| `relay-hangup.wav` | Gentle descending settle on End call |
